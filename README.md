# Sonam Acharya | Personal Portfolio

A visually stunning, high-performance personal portfolio website showcasing the skills, education, and software development projects of **Sonam Acharya**. Built from scratch using **React, TypeScript, and Vite** with custom **Vanilla CSS**.

---

## ✨ Features

- **🌙 Space Theme & Light Mode**: Default Obsidian Dark mode with custom HSL-tailored colors and glassmorphic designs, plus a toggleable Slate Light mode.
- **🧭 Scroll Tracking Navigation**: Sticky navigation header that automatically tracks your page scroll position and highlights the active section.
- **🛠️ Interactive Skills Board**: Tab-based skill categorization (Languages, Frontend, Backend, Tools) with hover micro-animations.
- **📂 Filterable Projects Showcase**: Categorized portfolio grid highlighting projects in MERN Stack, Python, and Java, complete with custom thematic SVG icons and direct GitHub repository links.
- **⏳ Journey Timeline**: Chronological vertical timeline representing academic milestones and professional experience.
- **✉️ Validated Contact Form**: Interactive message dispatcher with built-in client-side validation and responsive submission alerts.
- **📱 Fully Responsive Design**: Designed with CSS Grid and Flexbox layouts optimized to look stunning on mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Core Library**: React (v19)
- **Programming Language**: TypeScript (v5)
- **Styling Engine**: Custom CSS3 (variables, animations, glassmorphism)
- **Build Tool**: Vite (v8)
- **Icons**: Customized inline SVGs (fully optimized for performance and instant loading)

## 🚀 Getting Started

To run the project locally on your machine, follow these steps:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (version 18 or above recommended).

### 2. Clone the Repository
```bash
git clone https://github.com/Acharya-Sonam/portfolio.git
cd portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 5. Build for Production
To generate optimized production bundles under the `dist/` directory, run:
```bash
npm run build
```
